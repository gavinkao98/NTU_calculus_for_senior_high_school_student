Example. Show that \(\displaystyle\int_{3}^{\infty}\frac{dx}{\sqrt{x^{2}-x}}\) diverges.

  1. 前提檢查：\(x^{2}-x=x(x-1)\ge 6>0\) 於 \([3,\infty)\)，被積函數連續且為正（Thm 8.3 的假設）。
  2. 找下界：\(0 < x^{2}-x < x^{2}\Rightarrow\sqrt{x^{2}-x} < x\Rightarrow 0 < \frac1x < \frac{1}{\sqrt{x^{2}-x}}\)。即取 \(f=1/x\)（已知者，放下面）、\(g=1/\sqrt{x^{2}-x}\)（待判者）。
  3. 已知者發散：\(\int_{3}^{t}\frac{dx}{x}=\ln t-\ln 3\to\infty\)（§6.4 ＋ Thm 6.4），由 Def 8.1(a) 判發散。
  4. 由 Thm 8.3(b)，原積分發散。
  5. 方向這句不能省：同樣容易驗證 \(g\le\frac2x\) 於 \([3,\infty)\)，而 \(\int_{3}^{\infty}\frac{2\,dx}{x}\) 也發散——但這個比較什麼都證明不了。要判發散，已知發散的那一個必須在下面。
  6. 可選收尾：這個被積函數先配方再作正割代換（§8.3）也能求出原函數；判定收斂與否並不需要它。
